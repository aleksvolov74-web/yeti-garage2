# Yeti Garage 0.19.13 — быстрый тест на телефоне

1. Ещё → Руководство: на первом экране сразу 9 аккуратных карточек глав; текст не касается левой рамки.
2. Открыть «Самостоятельные действия» → страницы 210–211: вертикально долистать до нижней подсказки. Последняя строка/рисунок должны полностью уходить выше нижней границы.
3. На странице выполнить горизонтальный свайп: перейти на соседнюю непустую страницу. Вертикальный свайп не должен случайно менять страницу.
4. Вернуться «← Главы»: reader остаётся открыт, показывается список глав.
5. Нажать иллюстрацию: вверху видны − / текущий % / +. Проверить +, −, tap по %, pinch двумя пальцами, pan одним пальцем.
6. Открыть 3D и быстро тапнуть по модели сразу после появления: не должно быть `Invalid access ... direct_space_state ... null instance`.
