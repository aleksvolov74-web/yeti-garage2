## Важные ограничения

- Не считать геометрию литых деталей, крепления, порядок сборки, масляные каналы или ревизии подтверждёнными.
- Особенно важно: заводское руководство по CBZB предупреждает, что ослабление крышек коренных подшипников может деформировать постели коленвала. **Exploded view коленвала здесь показывает категорию детали, а не разрешённую операцию разборки.**
- ID `camshafts` уже присутствует в каталоге и означает один видимый распределительный вал CBZB. Не создавать второй вал и не выдумывать новый part_id. Русское название ID может быть во множественном числе в старых данных, но это НЕ подтверждает наличие двух валов.
- Отмечены только видимые в кадре реальные компоненты, координаты нормализованы 0..1; каждый номер уникален внутри node_id.
- В итоговой APK не показывать этот визуал как заводскую схему или VIN-exact. Нужен видимый статус `REFERENCE_ONLY`.
- `engine_bottom_end`, `boost_group` уже исправлены предыдущим частичным batch; эти файлы и запись их узлов менять нельзя. Старые общие пути WebP (`engine_bottom_end.webp`, `engine_upper_end.webp`) не переписывать и не удалять.
- Лицензия на заводские схемы: не копировать/не включать. Права на оригинальные сгенерированные иллюстрации и их дальнейшее использование определяются условиями генерации и использования сервиса.
