# Yeti Garage: контрольная точка проверки, не release candidate

Рабочая ветка `validation/full-marker-audit-android-ux`. Базовый commit a9c83e2, исправления ad7e63f, 3bdeae2, 8f4714f и fd19f92. Remote main проверен: e300886. Версия остаётся 0.20.29, versionCode 69, package com.yetigarage.app. Main не изменён, force push не использовался. Исходные незакоммиченные материалы и sidecar-файлы сохранены.

**Релиз не готов. Полный независимый визуальный аудит и интеграция 24 узлов не завершены. APK не собрана.** Найдены устранимые ошибки сохранения; они исправлены и проверены. Остальные ограничения перечислены ниже, без фиктивных PASS.

## Исправления

- Сохранение основного файла и резервных копий через временный файл, flush, проверку ошибки и rename. Рабочий файл не обнуляется до успешной записи временного.
- Повреждённый основной файл восстанавливается из валидной автоматической копии. Повреждённые оригиналы сохраняются с `.corrupt-*` перед заменой. Невалидная копия не затирает исправную.
- При повреждении обеих копий запись блокируется. Доступно восстановление через проверенную ручную копию или валидный перенос. Интерфейс сообщает об ошибке сохранения.
- Импорт проверяет типы контейнеров и записей, требует успешного backup перед обычным импортом, откатывает состояние в памяти после неудачной записи. Переключение деморежима прекращается при неудачном сохранении.
- Исправлен обнаруженный на реальных снимках дефект отсутствующих glyph: статусы без emoji, единица расходов `руб.` вместо неотображаемого знака. Проверены glyph и границы главной на четырёх размерах.
- Демопрофиль теперь согласован с DQ200: DSG 7 вместо МКПП.
- Добавлены воспроизводимые помощники для официального Godot ARM64 с отдельным Debian runtime; это прежнее локальное исправление окружения, теперь сохранённое в Git. Системные библиотеки не заменяются.
- UX-проверка расширена до 360×780, 390×844, 420×780 и 430×932. Добавлены проверки всех 246 исходных страниц руководства (526 индексных фрагментов объединяются существующим reader), последних текстовых блоков и девяти реальных кнопок глав.

Тест хранения использует отдельный каталог `user://storage-validation-*`, проверяет повторную загрузку истории, повреждение JSON, восстановление, сохранение повреждённых байтов, запрет записи, невалидный импорт, реальный отказ записи и откат, ручное восстановление и восстановление переносом. Файлы пользовательской истории не используются как тестовые фикстуры. Проверка не симулирует аппаратное отключение питания и не доказывает fsync/durability Android-файловой системы.

## Изображения и конкретный блокер

Inventory: 90 текущих изображений / 376 записей маркеров. Исторический active audit содержит 58 REFERENCE_ONLY, 15 NEEDS_IMAGE_REPLACEMENT, 7 FAIL_ARCHITECTURE, 6 NEEDS_REVIEW, 4 NOT_APPLICABLE_FWD. Это исторические заключения, не новый полный визуальный аудит. image_inventory.json содержит SHA каждого файла, part_id и координаты.

Найдены 35 прежних архивов; archive_inventory.json перечисляет технические изображения и manifest внутри них. Инвентаризация ZIP не заявляется проверкой всех CRC и не означает приёмку картинок. Старые rejected изображения не возвращались в проект.

Все 24 node_id сверены с существующим запросом. required_24_review.json сохраняет идентификаторы, SHA, исходные координаты, источники и текущий независимый статус. 23 старые ACCEPTED — только исторический статус; независимая повторная приёмка 127 точек не выполнена. Никакие координаты не придуманы и не перенесены на другие картинки. Применённых замен, новых part_id и новых маркеров: 0.

Просмотрены старое QA-наложение steering_column и пять входящих изображений: clutch_group, gearbox_group, rear_suspension_overview, rear_hub, rear_brake_assembly. Сверены SSP390 и рисунок S42-0347 FWD. Это не приёмка всех остальных изображений. Общая архитектура сухого сцепления согласуется с SSP; полная кинематика синтетической коробки и точная геометрия заднего узла остаются непроверенными. Видимый привод ручника не подтверждает PR-вариант тормоза.

**Блокер G85:** сервисная информация Yeti Gen3 размещает датчик внутри рулевого механизма. На старом изображении маркер указывает на закрытый корпус. У входящего комплекта нет изображения и трёх координат рулевого узла. Достоверный внутренний вид с идентифицированным чувствительным элементом и подтверждённой применимостью не найден. Контактное кольцо, внешний корпус или G269 не подходят в качестве замены. Генератор доступен, но не является доказательством геометрии.

Минимальный внешний материал для устранения этого блокера: разрешённая к использованию сервисная иллюстрация, фото разобранного узла с однозначной идентификацией или CAD внутреннего G85 именно применимого Yeti Gen3. Вручную расставлять маркеры пользователю не нужно. Далее остаются независимая проверка остальных 127 точек, полный kit, интеграция и runtime QA.

## Android и выпуск

Локально Java 17 не запускается: `Failed to mark memory page as executable`. Повтор с `-Xint` также неуспешен. SDK и export templates по настроенным путям отсутствуют; export_credentials отсутствует. Доступная альтернатива — действующий GitHub Actions container с Godot/SDK/JDK, после завершения каталога. Текущий workflow экспортирует debug APK; production release signing отдельно не подтверждён.

ADB работает, устройств нет. Для окончательной Android-проверки потребуется устройство, доступное ADB, после сборки полной версии. Наличие старых APK в Download не является проверкой новых исправлений. Новый APK SHA256: отсутствует, APK не создана.

Единый реестр ISSUES.json; машиночитаемая точка продолжения PROGRESS.json. Версия не повышалась. Release notes и changelog относятся к исправлениям и ограничениям этой контрольной точки, не к успешному релизу.
