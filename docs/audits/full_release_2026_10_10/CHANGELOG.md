# Изменения контрольной точки 2026-10-10

Версия приложения остаётся 0.20.29 / 69. Это не выпуск APK.

- Исправлены сохранение и автоматическое восстановление повреждённой истории.
- Повреждённые оригиналы сохраняются отдельно; ошибки записи показываются пользователю.
- Добавлена проверка структуры импорта и откат после неудачной записи.
- Исправлены утечки AWD в глобальном поиске, списках/карточках FWD и устаревший кеш профиля каталога. AWD reference доступность сохранена.
- Заменены неотображаемые emoji и знак валюты читаемыми обозначениями.
- Исправлено противоречие коробки в демопрофиле.
- Сохранён в Git воспроизводимый ARM64 runtime для headless/desktop проверок.
- Добавлены тесты recovery/rollback, всех страниц руководства и четырёх размеров UI.
- Созданы текущий реестр проблем, инвентарь изображений/архивов и QA-наложения.

Изображения, part_id и координаты каталога не изменены. Замены 24 узлов не интегрированы; шлюз APK остаётся закрытым.
