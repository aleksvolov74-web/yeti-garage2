# Yeti Garage 0.19.12 — manual reader fix

- Руководство открывается сразу списком из 9 кликабельных глав; отдельного popup «Содержание» больше нет.
- Выбор главы меняет страницу внутри того же окна руководства и не закрывает reader.
- В режиме чтения есть компактная кнопка «← Главы», номер страницы, свайп влево/вправо и стрелки назад/вперёд.
- После каждого динамического рендера страницы повторно применяются touch-target/mouse-filter правила — блоки, плашки и иллюстрации не должны перехватывать вертикальный свайп.
- ScrollContainer руководства помечен preserve_scroll_modes, поэтому глобальный touch-polish не меняет его режимы прокрутки.
- Просмотрщик схем: три всегда помещающиеся кнопки «− / текущий % / +», сброс по нажатию на процент, масштаб 100–500%, pinch двумя пальцами.
- Горизонтальная прокрутка увеличенной схемы больше не отключается глобальной функцией _apply_touch_targets().
- Viewer схемы создаётся дочерним окном manual popup, чтобы открытие схемы не уничтожало reader.
- 3D-код не изменялся.
