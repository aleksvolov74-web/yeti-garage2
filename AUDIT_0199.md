# Yeti Garage 0.19.9 — UI polish audit

## Исправлено

- Убран последний системный AcceptDialog UI: формы пробега, истории пробега, интервалов ТО, события, деталей события и истории детали теперь используют единый PopupPanel в цветах приложения.
- Везде сохранены крупные зоны нажатия, явная кнопка × и нижние действия.
- Длинные формы и списки листаются свайпом без видимого scrollbar.
- Главная фиксирована на целевом 430×932, но на экранах ниже 900 px включается скрытый вертикальный свайп, чтобы карточки не обрезались.
- Исправлено несоответствие комментария и реального поведения главного ScrollContainer.
- Текст руководства увеличен: основной текст 17 px, bullets 16 px, подзаголовки 18 px.
- В настройке интервала ТО добавлено пояснение про приоритет сервисной книжки/документации конкретной машины.
- Удалены неиспользуемые helpers старых системных диалогов.
- Убрана дублирующая строка theme override для hover-цвета кнопок.
- Версия поднята до 0.19.9-ui-polish / Android versionCode 28.
- 3D-файл сохранён без изменений.

## Что не притворяемся сделанным

- Android Notification Scheduler не встроен: для него нужен внешний plugin + Gradle build template.
- Встроены все 177 оригинальных схем и иллюстраций из PDF. Они привязаны к соответствующим «Илл.» на 124 страницах; по нажатию открываются крупно с масштабом 100–400%.

## Статические проверки

- все res:// ссылки должны существовать;
- JSON руководства должен парситься и содержать 246 документных страниц;
- в app.gd не должно остаться создания AcceptDialog/ConfirmationDialog;
- файл 3D должен совпасть SHA-256 с 0.19.7.

## Проверка иллюстраций 0.19.9
- Найдено в PDF: 177 встроенных изображений на 124 страницах с `figure_ref`.
- Совпадение на каждой странице: количество `figure_ref` = количеству встроенных PDF-изображений.
- В приложение перенесено: 177/177 JPEG (RGB), общий объём ~3.34 MB.
- Нумерация проверена: `Илл. 1` … `Илл. 177`, пропусков и дублей нет.
- Все пути `res://assets/manual/figures/...` существуют.
- SHA-256 `scenes/vehicle_3d/vehicle_3d_view.gd` совпадает с 0.19.8 — 3D не менялся.
- Runtime-проверка в Godot остаётся обязательной перед APK: в текущей среде нет бинарника Godot.
