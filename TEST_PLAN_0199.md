# Контрольный прогон 0.19.9 перед APK

1. Открыть проект в Godot 4.7.2 без красных runtime-ошибок.
2. На 430×932 проверить: главная не прокручивается, все карточки видны и кликабельны.
3. На 360×800 проверить: главная листается обычным свайпом, scrollbar не виден.
4. Проверить: карандаш машины, копирование VIN, пробег, двигатель, поиск, обслуживание, напоминания, расходы.
5. Пробег: добавить запись → открыть историю → исправить → удалить. Все окна должны быть тёмными popup-карточками, без системного белого диалога.
6. История: создать событие, пролистать длинную форму, сохранить, открыть детали, отредактировать и удалить.
7. ТО: открыть «Интервал», изменить значение, сохранить; «Выполнено сейчас» должно требовать подтверждение.
8. Руководство: открыть длинную страницу, проверить читаемость 17 px, свайп, предыдущую/следующую страницу и переход из поиска.
9. Поиск: `антифриз`, `не заводится`, `тормоза`, `масло`, `предохранители`; открыть результат руководства.
10. «Ещё»: переносимая копия, импорт, локальная резервная копия, руководство.
11. Открыть 3D и вернуться. Ничего в 3D не редактировать.

После успешного прогона экспортировать `Android Quick APK`.

## Руководство: изображения 0.19.9
- Открыть страницы документа 9, 34, 69, 94, 159 и 226: под соответствующей подписью «Илл.» должна отображаться оригинальная схема.
- Нажать на схему: открывается отдельное тёмное окно с подписью.
- Проверить кнопки − / 100% / +: масштаб меняется от 100% до 400%, увеличенное изображение прокручивается по горизонтали и вертикали.
- В глобальном поиске найти «радиоключ», «климатроник», «заднее сиденье»: у результата страницы с рисунком есть превью и пометка «На странице есть схема / иллюстрация».
- Пройти статическую проверку: 177 figure_ref -> 177 существующих JPEG; номера Илл. 1–177 совпадают с именами ресурсов.
