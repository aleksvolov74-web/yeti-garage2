# Yeti Garage 0.19.13 — reader polish audit

Фокус: руководство на телефоне + известная runtime-ошибка 3D selection.

## Исправлено
- Список глав: отступы, размер текста, высота карточек, selected/hover/pressed состояния.
- Убран визуально висящий текст «9 глав».
- Нижние кнопки перелистывания перенесены в верхнюю строку навигации, освобождена высота страницы.
- Убрана фиксированная минимальная высота `content_panel`, увеличен нижний запас ScrollContainer.
- В конец каждой страницы добавлен технический нижний запас и подсказка о горизонтальном свайпе.
- Автосклейка переносов пунктов, разорванных PDF-экстракцией.
- Нормализация `■` в заметках и предупреждениях.
- Viewer схем: компактные контролы, 100–500%, pinch/pan сохранены.
- 3D raycast: null-guard для `subviewport.world_3d` / `direct_space_state`.

## Статические проверки
- JSON руководства валиден.
- 246 страниц в индексе.
- 177 figure_ref с файлами изображений.
- Все пути изображений из figure_ref существуют.
- Проверка дублирующихся имён функций в GDScript.
- Проверка `res://` ссылок на локальные ресурсы.
- Проверка ZIP после упаковки.

## Что всё ещё требует живого запуска
Без установленного Godot в рабочем окружении нельзя честно подтвердить touch-layout на конкретном Android. На телефоне проверить:
1. список глав и его отступы;
2. вертикальный скролл до отметки конца страницы на длинной странице 210/211;
3. свайп влево/вправо после вертикального чтения;
4. − / % / + и pinch в viewer схем;
5. ранний тап по 3D после открытия — ошибка `direct_space_state` не должна появляться.
