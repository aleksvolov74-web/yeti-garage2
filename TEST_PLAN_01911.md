# Проверка 0.19.11

1. Открыть Ещё → Руководство ŠKODA Yeti.
2. Нажать «Содержание»: должен открыться список разделов; нажатие по разделу сразу переводит на его страницу.
3. На странице провести пальцем справа налево: перейти на следующую непустую страницу. Слева направо: на предыдущую. Вертикальный свайп должен продолжать прокручивать текст.
4. На странице с иллюстрацией нажать картинку: окно должно открыться сразу на 165%.
5. Кнопки − / + / «По ширине» должны быть видны над схемой. Проверить увеличение до 400% и перемещение увеличенной схемы пальцем.
