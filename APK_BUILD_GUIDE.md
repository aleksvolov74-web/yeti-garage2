# APK: безопасный первый экспорт

## Перед любым удалением старой установки

1. Открой **Ещё → Копировать данные для переноса**.
2. Сохрани длинный текст из буфера обмена вне Yeti Garage: в заметках, сообщении себе или файле.
3. Только после этого экспериментируй с standalone APK.

Локальная резервная копия внутри приложения не заменяет переносимую: она живёт в sandbox текущей установки и может исчезнуть при удалении приложения.

## Вариант 1 — быстрый APK

Выбери export preset **Android Quick APK**.

- использует pre-built APK template Godot;
- Gradle выключен;
- GABE не нужен;
- подходит для проверки standalone приложения на телефоне;
- внутренние напоминания работают;
- системные Android-уведомления через Notification Scheduler недоступны.

Перед экспортом должны быть установлены export templates именно для Godot 4.7.2.

## Вариант 2 — APK с системными уведомлениями

Выбери **Android Gradle (notifications)** только после подготовки:

1. Установить GABE и Rootfs.
2. В Godot установить Android Build Template.
3. Добавить Notification Scheduler v2 plugin в проект и включить его.
4. Проверить тест уведомления в редакторе/сборке.
5. Экспортировать Gradle preset.

## Установка поверх старого APK

Package id сохранён: `com.yetigarage.app`.

Но Android требует совпадения подписи APK. Если старый APK был подписан другим debug/release ключом, обновление поверх него не установится. В этом случае сначала сохрани переносимую копию, затем удаляй старое приложение, ставь новое и используй **Ещё → Импортировать данные из буфера**.
