# Yeti Garage 0.19.22 local — manual pagination rebuild

Главное изменение: длинные исходные страницы руководства больше не пытаются жить одной гигантской прокруткой.

- 246 исходных документных страниц сохранены как источник.
- После безопасного деления длинных страниц в приложении: 526 экранных подстраниц.
- 210 длинных исходных страниц разбиты на 2–4 части.
- Оригинальный номер страницы ŠKODA не меняется: подпись выглядит как `стр. 208 • 1/2`.
- Ссылки внутри текста вида `стр. 207` остаются оригинальными ссылками руководства.
- Иллюстрации не дублируются и не теряются: каждая остаётся ровно в одном из фрагментов исходной страницы.
- Большие предупреждения/примечания режутся по исходным пунктам `■` и предложениям, а не посередине слова.
- Длинные обычные абзацы режутся по границам предложений; длинная логическая пуля сохраняет маркер только в первой части.
- Поиск индексирует конкретный фрагмент, поэтому результат открывает именно ту подстраницу, где найден текст.
- Навигация по главам пересчитана под новый внутренний индекс.
